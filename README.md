# Mini NPU Simulator

## 1. 프로젝트 개요

Mini NPU Simulator는 NPU(Neural Processing Unit)의 기본적인 연산 원리를 이해하고, MAC(Multiply-Accumulate) 연산을 활용하여 입력 패턴과 필터 간의 유사도를 비교하는 프로그램입니다.

두 개의 필터와 입력 패턴을 대상으로 MAC 연산을 수행하고, 계산된 점수를 비교하여 입력 패턴이 어떤 필터에 더 가까운지 판정합니다.

또한 수동 입력 모드와 JSON 자동 분석 모드를 제공하며, 다양한 행렬 크기에 따른 연산 성능을 측정할 수 있습니다.

## 2. 프로젝트 목표 및 선정 이유

### 2.1 프로젝트 목표

- Python 클래스와 메서드를 활용한 객체지향 프로그래밍 학습
- 2차원 리스트를 활용한 행렬 연산 구현
- MAC 연산을 통한 패턴 분류 기능 구현
- JSON 파일을 활용한 테스트 데이터 관리
- 예외 처리를 통한 잘못된 입력 데이터 검증
- `time.perf_counter()`를 활용한 연산 성능 측정

### 2.2 주제 선정 이유

NPU는 인공지능 연산에 특화된 프로세서로, 행렬 연산과 MAC 연산을 반복적으로 수행합니다.

이 프로젝트에서는 NPU의 기본적인 연산 원리를 간단한 Python 프로그램으로 구현하여 행렬 연산, 데이터 검증, 패턴 판정 및 성능 측정 과정을 이해하고자 주제를 선정했습니다.

## 4. 주요 기능

### 4.1 수동 입력 모드

사용자가 직접 3×3 행렬 데이터를 입력하여 패턴을 분석하는 기능입니다.

- 필터 A, 필터 B 및 입력 패턴 데이터 입력
- 공백을 기준으로 입력 데이터 분리
- 입력 데이터의 개수 및 자료형 검증
- 3×3 행렬 생성
- MAC 연산 및 패턴 판정
- 연산 결과와 소요 시간 출력

### 4.2 JSON 자동 분석 모드

`data.json`에 저장된 테스트 데이터를 불러와 자동으로 패턴을 분석하는 기능입니다.

- JSON 파일 로드
- 테스트 케이스 반복 실행
- 필터 및 패턴 행렬 검증
- MAC 연산 및 A/B 필터 비교
- 예상 결과와 실제 결과 비교
- PASS / FAIL 결과 판정
- 전체 테스트 결과 집계

### 4.3 MAC 연산

MAC(Multiply-Accumulate)은 두 행렬의 동일한 위치에 있는 원소끼리 곱한 후 모든 결과를 누적하는 연산입니다.

계산 공식:

\[
MAC = \sum_{i=0}^{N-1}\sum_{j=0}^{N-1} A_{ij} \times B_{ij}
\]

필터 A와 입력 패턴, 필터 B와 입력 패턴을 각각 MAC 연산하여 점수를 계산합니다.

점수가 높은 필터를 입력 패턴과 더 유사한 필터로 판정합니다.

### 4.4 패턴 판정 및 epsilon 처리

두 필터의 MAC 점수를 비교하여 최종 결과를 결정합니다.

| 판정 조건 | 결과 |
|---|---|
| A 점수가 B 점수보다 높고 차이가 epsilon 이상 | A |
| B 점수가 A 점수보다 높고 차이가 epsilon 이상 | B |
| 두 점수의 차이가 epsilon 미만 | UNDECIDED |

- epsilon: `1e-9`
- 부동소수점 연산에서 발생할 수 있는 미세한 차이를 고려하여 판정합니다.

### 4.5 성능 측정

행렬 크기에 따른 MAC 연산 성능을 측정합니다.

- 측정 대상: 3×3, 5×5, 13×13, 25×25
- 측정 방법: 동일한 MAC 연산을 10회 반복
- 측정 도구: `time.perf_counter()`
- 시간 단위: 밀리초(ms)
- 각 테스트 케이스의 평균 시간을 계산하고, 동일한 행렬 크기를 가진 케이스들의 평균을 다시 계산합니다.

연산 횟수는 행렬의 행과 열의 곱으로 계산합니다.

\[
연산 횟수 = 행렬 크기 \times 행렬 크기
\]

## 7. JSON 데이터 설명

`data.json`은 자동 분석 모드에서 사용할 테스트 데이터를 저장하는 파일입니다.

테스트 케이스에는 다음 정보가 포함됩니다.

| 데이터 항목 | 설명 |
|---|---|
| `size` | 행렬 크기 |
| `filter_a` | 필터 A 행렬 |
| `filter_b` | 필터 B 행렬 |
| `pattern` | 분석 대상 패턴 행렬 |
| `expected` | 예상 판정 결과 |

실제 JSON 파일의 키 이름 및 구조에 맞게 수정합니다.

### JSON 데이터 예시

```json
{
    "size": 3,
    "filter_a": [
        [1, 0, 1],
        [0, 1, 0],
        [1, 0, 1]
    ],
    "filter_b": [
        [0, 1, 0],
        [1, 0, 1],
        [0, 1, 0]
    ],
    "pattern": [
        [1, 0, 1],
        [0, 1, 0],
        [1, 0, 1]
    ],
    "expected": "A"
}
```

※ 위 내용은 JSON 데이터 구조를 설명하기 위한 예시입니다. 실제 `data.json`의 키 이름과 구조를 기준으로 작성해야 합니다.
